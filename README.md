# Mini-htop

โปรแกรมดูการใช้ CPU, RAM, Swap, พื้นที่ดิสก์ และโปรเซสแบบอัปเดตต่อเนื่องบน Terminal เขียนด้วยภาษา C สำหรับวิชา Operating Systems and System Calls Programming

> โปรแกรมนี้รันบน **Linux หรือ Ubuntu ใน WSL** ไม่ได้รันบน Windows โดยตรง และจะแสดงเฉพาะโปรเซสฝั่ง Linux/WSL ไม่แสดงเกมหรือโปรแกรมที่รันบน Windows

## เริ่มใช้งานบน Windows + WSL

ต้องมี Ubuntu ใน WSL และมี `gcc` กับ `make` ก่อน หากยังไม่มีเครื่องมือคอมไพล์ใน Ubuntu ให้รัน `sudo apt update` แล้ว `sudo apt install build-essential`

### 1. เปิด PowerShell ในโฟลเดอร์โปรเจกต์

เปิดโฟลเดอร์ Mini-htop ใน File Explorer ให้เห็นไฟล์ `Makefile` จากนั้นคลิกแถบที่อยู่ด้านบน พิมพ์ `powershell` แล้วกด Enter

### 2. เข้า Ubuntu

ใน PowerShell พิมพ์:

```powershell
wsl -d Ubuntu
```

ถ้าชื่อ Ubuntu ในเครื่องไม่ใช่ `Ubuntu` ให้ดูชื่อด้วย `wsl --list` ใน PowerShell แล้วใช้ชื่อนั้นแทน

### 3. คอมไพล์และเปิดโปรแกรม

เมื่อเข้ามาใน Ubuntu แล้ว พิมพ์:

```bash
ls Makefile
make
./mini-htop
```

ถ้า `ls Makefile` แจ้งว่าไม่พบไฟล์ แปลว่ายังอยู่ผิดโฟลเดอร์ ให้ใช้ `cd` ไปยังโฟลเดอร์โปรเจกต์ของคุณก่อน ไม่ต้องใช้ path ของผู้พัฒนา

## เริ่มใช้งานบน Linux

เปิด Terminal ในโฟลเดอร์ที่มีไฟล์ `Makefile` แล้วรัน:

```bash
make
./mini-htop
```

Terminal ควรกว้างประมาณ 80 คอลัมน์ขึ้นไป โปรแกรมไม่ต้องใช้ Python

## ใช้ปุ่มอะไรบ้าง

| ปุ่ม | ทำอะไร |
| --- | --- |
| `/` | พิมพ์ชื่อโปรเซสหรือ PID เพื่อค้นหา แล้วกด Enter |
| ลูกศรขึ้น/ลง หรือ `j`/`k` | เลือกโปรเซสในตาราง |
| `c`, `m`, `p`, `n` | เรียงตาม CPU, RAM, PID หรือชื่อ |
| `t` | ส่ง `SIGTERM` ให้โปรเซสที่เลือก (ต้องกด `y` ยืนยัน) |
| `K` ตัวใหญ่ | ส่ง `SIGKILL` (ต้องกด `y` ยืนยัน) |
| Space | หยุดหรือเริ่มอัปเดตข้อมูลต่อ |
| `r` | รีเฟรชทันทีเมื่อไม่ได้หยุดอัปเดต |
| `q` | ออกจากโปรแกรม |

หน้าจอจะอัปเดตข้อมูลประมาณทุก 1 วินาที ค่า CPU% ของโปรเซสที่ใช้หลาย Core อาจมากกว่า 100% ได้ เพราะเทียบกับกำลังประมวลผลของหนึ่ง Core

## ลองเดโมให้เห็น CPU% ขยับ

เปิด Terminal อีกหน้าต่างในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
make demo-load
./demo-load
```

ปล่อยหน้าต่างนี้ไว้ จากนั้นเปิด `./mini-htop` ในอีกหน้าต่าง กด `/` พิมพ์ `demo-load` แล้วกด Enter จะเห็นโปรเซสทดลองและค่า CPU% ของมัน

ถ้าต้องการสาธิตการยุติโปรเซส ให้ตรวจ PID ว่าตรงกับ `demo-load` ที่สร้างเอง กด `t` แล้วกด `y` โปรเซสจะพิมพ์ข้อความก่อนปิดตัว ถ้าเปิด `./demo-load` ใหม่แล้วใช้ `K` ตัวใหญ่ โปรเซสจะหยุดทันทีโดยไม่มีข้อความปิดตัว

**อย่าใช้ `sudo` ในการเดโม และอย่าส่ง Signal ไปยังโปรเซสสำคัญของระบบ** `SIGKILL` บังคับยุติโปรเซส ส่วน `SIGTERM` เปิดโอกาสให้โปรเซสปิดตัวอย่างเรียบร้อย โปรแกรมมีข้อความให้ยืนยันและตรวจ PID อีกครั้งก่อนส่ง Signal แต่ยังมีโอกาสเล็กน้อยที่ PID จะเปลี่ยนระหว่างการตรวจสอบกับการส่ง Signal

## ทดสอบและดูข้อมูลครั้งเดียว

รันชุดทดสอบ:

```bash
make test
```

ดูข้อมูลหนึ่งครั้งโดยไม่เปิดหน้าจอแบบโต้ตอบ:

```bash
./mini-htop --once
```

ชุดทดสอบส่ง Signal เฉพาะให้ child process ที่สร้างขึ้นเอง ไม่ยุติโปรเซสอื่นในเครื่อง

## โปรแกรมทำงานอย่างไร

โปรแกรมอ่านข้อมูล CPU, RAM และโปรเซสจาก `/proc` ของ Linux ใช้ `statvfs()` อ่านพื้นที่ดิสก์ และใช้ `kill()` ส่ง Signal รายละเอียด POSIX APIs และสูตรคำนวณอยู่ใน [รายงาน](docs/REPORT.md)
